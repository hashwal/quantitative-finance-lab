# Project 001 — Equity returns and risk

**Status:** In progress; no empirical findings yet.

## Research question
Which of AAPL, MSFT, NVDA, GOOGL and AMZN delivered the highest historical risk-adjusted return over 2021–2025? Compare with SPY as a benchmark. This is a retrospective selected-universe comparison, not evidence of a predictive strategy.

## Tasks
- [ ] Calculate simple and log returns manually.
- [ ] Implement and test return functions in Python.
- [ ] Obtain permitted adjusted daily price data; document source, retrieval date, adjustments and missing observations.
- [ ] Calculate CAGR, annualized volatility, Sharpe and Sortino ratios, maximum drawdown, correlation, beta and alpha.
- [ ] Document risk-free rate, annualization and benchmark assumptions.
- [ ] Plot cumulative wealth, drawdowns and return distributions.
- [ ] Write findings, limitations and reproducibility instructions.

Start with [Lesson 1](lesson-01.md). Do not redistribute restricted market data. No investment recommendation is implied.
